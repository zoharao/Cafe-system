# Zoha Restaurant - Cafe Management System

A web-based cafe management system built with HTML, CSS, and JavaScript.

## 🚀 Features
* Browse menu items and pricing
* Dark mode toggle functionality
* Clean and responsive user interface

## 🛠️ Built With
* **HTML5:** Structure and markup
* **CSS3:** Styling and layout design
* **JavaScript:** Interactivity and menu logic
